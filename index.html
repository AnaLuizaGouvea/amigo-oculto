Amigo oculto

Você envia os links pelo WhatsApp, mas não vê quem tirou quem. Cada pessoa abre o próprio envelope.

Esta página está aberta como arquivo local. Para os links funcionarem no celular dos participantes, publique-a na web (por exemplo, GitHub Pages ou Netlify) e abra por lá.

Os tamanhos são opcionais; separe cada um por vírgula.

Sorteio feito. Envie para cada pessoa

Abra o WhatsApp para cada participante e envie a mensagem manualmente. Depois, marque o envio como concluído.

Atenção: os links contêm o resultado codificado, mas não criptografado. Quem tiver acesso ao link poderá descobrir o resultado. Sem um backend, também não é possível invalidar links antigos.
